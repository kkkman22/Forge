# /forge fix

Bugfix three-file workflow entry point.

## 1. Entry

When `/forge fix` is invoked:

1. Detect spec kind using `detectSpecKind` (from `src/spec-kind.ts`).
2. If `bugfix.md` exists in `.forge/specs/<feature>/`, load the bugfix bundle via `loadSpecBundle`.
3. Call `runBugfixOrchestration(bundle)` (from `src/spec-bugfix-orchestration.ts`) to generate bugfix design and tasks.
4. Write generated files to `.forge/specs/<feature>/`.
5. Proceed to `/forge build` for execution.

## 2. Bugfix Three-File Layout

```
.forge/specs/<feature>/
├── bugfix.md          # Current / Expected / Unchanged sections
├── design.md          # Generated by runBugfixOrchestration
└── tasks.md           # Generated by runBugfixOrchestration
```

## 3. Integration

- `detectSpecKind(files, "fix")` → returns "bugfix"
- `loadSpecBundle(featureDir)` → loads bugfix.md as primary
- `runBugfixOrchestration(bundle)` → generates design + tasks
- `derivePbtTasksFromUnchanged(bundle)` → appends regression-test tasks to tasks.md

## 4. Fallback

If `bugfix.md` doesn't exist, fall back to `/forge build` with bugfix mode.
