# Bugfix Method Library

> 条件加载：仅当 `work_nature=bugfix` 时加载到 build 上下文。

## 根因六分类

| 类别 | 典型模式 | 识别方法 | 修复策略 |
|------|---------|---------|---------|
| 逻辑 | 条件分支遗漏、运算符错误、循环边界 | 跟踪正常 vs 失败路径分叉点 | 修正条件/运算/边界 |
| 状态 | 状态机转换缺失、竞态、陈旧缓存 | 断点/日志追踪状态变量生命周期 | 补充转换/加锁/失效策略 |
| 数据 | 类型不匹配、null/undefined、边界值 | 输入域分析 + 防御性断言 | 类型收窄 + 防御检查 |
| 并发 | 竞态条件、死锁、时序依赖 | 并发场景复现 + 日志时序分析 | 同步原语/串行化/无锁结构 |
| 配置 | 环境差异、缺失配置、默认值错误 | 配置 diff（dev/staging/prod） | 配置统一 + 显式声明 |
| 缺防御 | 未校验外部输入、未处理错误、未设超时 | 边界分析 + 威胁建模 | 防御性编程 + 超时/重试 |

## 日志调试升级模板

### 第 1 轮（关键路径）

1. 在 failure 前后添加 `console.log` / `debug` 日志
2. 记录关键变量值、函数入口/出口
3. 运行复现步骤
4. 分析日志输出
5. 调整修复方案

### 第 2 轮（扩大范围）

1. 扩大日志到上游调用链
2. 检查异步操作时序
3. 验证中间状态
4. 重新分析

### 失败回退

2 轮后仍失败 → 回 analyze 阶段重新做根因分析。

**日志清理**：调试完成后删除所有临时日志。
