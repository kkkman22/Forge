# Category Heuristics for Recap

Classification rules for commits and tasks:

| Category | Keywords / Patterns |
|----------|-------------------|
| feature | `feat:`, `add`, `implement`, `create` |
| bugfix | `fix:`, `bug`, `patch`, `hotfix` |
| refactor | `refactor:`, `restructure`, `rename`, `move` |
| infra | `ci:`, `build:`, `deploy`, `config` |
| docs | `docs:`, `readme`, `changelog` |
| uncategorized | no matching keywords |
